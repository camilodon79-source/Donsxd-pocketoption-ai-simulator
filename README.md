# DONSXD POCKET-OPTION AI

Application de simulation d'analyse de trading avec interface professionnelle.

## ⚠️ AVERTISSEMENT IMPORTANT

Cette application est **UNIQUEMENT UNE SIMULATION**. 
- Aucune connexion réelle à Pocket Option
- Aucune API de trading réelle
- Aucun argent réel impliqué
- Les données sont entièrement simulées localement
- Les signaux ne représentent pas de vraies recommandations de trading

## 🚀 Installation et Lancement

### Méthode 1 : Simple (Recommandée)

1. Téléchargez tous les fichiers dans un même dossier
2. Double-cliquez sur `index.html`
3. L'application s'ouvre dans votre navigateur

### Méthode 2 : Serveur Local

Utilisez un serveur local simple :

```bash
# Avec Python 3
python -m http.server 8080
